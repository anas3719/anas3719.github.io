# صفحة بورتفوليو مودل

صفحة شخصية عربية جاهزة للتقديم على الإعلانات والتعاونات التجارية.

الموقع الرسمي: <https://anas3719.github.io/>

لوحة إدارة الأعمال: <https://anas3719.github.io/portfolio-admin.html>

## تعديل البيانات

- الاسم ومعلومات التواصل محدثة لأنس عمر.
- لتغيير البريد، الانستغرام، أو الواتساب لاحقًا عدل قسم `contact` في `index.html`.
- عدل المدينة، المجالات، والمقاسات في قسم `details`.

## إضافة الصور

أنشئ مجلدًا باسم `assets` بجانب الملفات، ثم أضف صورك بهذه الأسماء:

- `hero.jpg`
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`

الصفحة تعمل حتى بدون الصور، لكنها ستظهر بشكل أفضل عند وضع صورك الحقيقية.
